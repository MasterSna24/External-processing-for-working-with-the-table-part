Внешняя обработка по работе табличной частью

Внешняя обработка для тренировки работы с табличной частью.

1.По кнопке "Сгенерировать список" запускается заполнение табличной части.Количество строк и длина в символах каждой строки Задается в полях "Колво строк" и "Дл строки"

2. Подсвечиваются строки в заполненной таблице, содержащие указанную в поле формы "Название для поиска" комбинацию символов.

3. По кнопкам "Список дублей" и "Список дублей(запрос)" запускают процедуры поиска дублей по заполненным значениям:
перечислением номеров строк попарно, например:
Значение eab790 в строке 1023 дублируется в строке 6740
Значение eab790 в строке 1023 дублируется в строке 2000.

первая кнопка делает это программно, вторая через запрос.

4. Кнопка "Удаление дублей" удаляет повторяюшиеся значения(дублями считается каждое встреченное значение после первого вхождения в список).

5. Кнопка "Наоборот" зеркально переворачивает символы в каждой строке. Например: строка была eab790 стала 097bae
